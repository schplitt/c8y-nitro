# Platform Behavior

Where the Cumulocity platform differs from its [API docs](https://cumulocity.com/api/core/), or where the docs leave a question open that a microservice runs into. Every row names a behavior the fake tenant of [`c8y-nitro/testing`](/guide/testing) emulates **and** a contract scenario checks it against a real tenant (`pnpm test:contract`). A test keeps this page and the scenarios in sync: every id here is verified by a scenario, and every scenario's `verifies` list points here.

Checked on a tenant of the eu-latest environment in November 2026. If a row no longer holds on your tenant, please [open an issue](https://github.com/schplitt/c8y-nitro/issues).

## Inventory

| Id                                     | The Docs Say                                                              | The Platform Does                                                                                                                                                                                                                                  |
| -------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `query-ne-rejected`                    | The query language lists `ne` among the operators.                        | `ne` is rejected with 422, like any operator outside `eq`, `gt`, `ge`, `lt`, and `le`.                                                                                                                                                             |
| `query-upper-case-operators`           | Operators are written in lower case.                                      | `AND`, `OR`, `NOT`, and `EQ` are rejected with 422.                                                                                                                                                                                                |
| `query-has-standard-property`          | `has()` is "not supported" for standard properties.                       | `has(name)`, `has(type)`, `has(owner)`, `has(id)`, `has(creationTime)`, and `hasany()` with them answer 200 with no matches.                                                                                                                       |
| `query-literal-left-side`              | The left side of a comparison is a property.                              | A quoted left side (`'name' eq 'x'`) is accepted and read as the property `name`; `'a' eq 'a'` matches nothing.                                                                                                                                    |
| `query-invalid-path`                   | Nothing about path syntax.                                                | Paths with `/` or `[`, such as `groups/id` and `externalIds["serialNumber"].id`, are rejected with 422.                                                                                                                                            |
| `query-function-arguments`             | `bygroupid()` and `isinhierarchyof()` take ids; `has()` takes a fragment. | Arguments are not validated: `bygroupid(abc)` and `bygroupid(eq, 'x')` are accepted and match nothing, `has('x')` works like `has(x)`.                                                                                                             |
| `query-date-literals`                  | A `.date` comparison takes a date-time string.                            | The literal needs a date and a time (`'2020-01-01T00:00'`; seconds, fraction, and zone optional, one-digit fields fine). Any other value (`'2020-01-01'`, `'yesterday'`) matches nothing; impossible fields (`'2020-13-01T00:00:00Z'`) answer 422. |
| `query-typed-values`                   | Decimals need an `f`/`d` suffix.                                          | Values are typed: a number never matches a string property, a quoted number or an unsuffixed decimal is a string, `true`/`false` match booleans only.                                                                                              |
| `query-type-ignored`                   | Nothing.                                                                  | The `type` parameter is ignored when `query` or `q` is given.                                                                                                                                                                                      |
| `orderby-type-order`                   | Nothing about mixed types.                                                | `$orderby` sorts missing values first (ascending) or last (descending), then numbers, then strings, then booleans: MongoDB's order.                                                                                                                |
| `orderby-byte-wise`                    | Nothing.                                                                  | Strings sort by character code: upper case before lower case, `AH-VW-10` before `AH-VW-100` before `AH-VW-14`.                                                                                                                                     |
| `orderby-arrays`                       | Nothing.                                                                  | An array property sorts by its smallest element ascending and by its largest descending.                                                                                                                                                           |
| `with-children-false-empty-references` | `withChildren` defaults to `false`.                                       | Without the parameter the child references are included; `withChildren=false` keeps `childDevices`, `childAssets`, and `childAdditions` with empty `references`.                                                                                   |
| `parents-only-with-parameter`          | Parent references are properties of the managed object.                   | `deviceParents`, `assetParents`, and `additionParents` are only filled with `withParents=true`, as `{ managedObject }` with the full parent.                                                                                                       |

## Paging

| Id                        | The Docs Say                                 | The Platform Does                                                                                                            |
| ------------------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `paging-total-pages-zero` | `totalPages` counts the pages.               | An empty result reports `totalPages: 0` with `withTotalPages=true`.                                                          |
| `paging-next-past-end`    | `next` links the next page.                  | Every page carries a `next` link, also the last one and pages past the end, unless `withTotalPages=true` says there is none. |
| `paging-page-size-422`    | `pageSize` is an integer between 1 and 2000. | `pageSize=0` means 1, larger values are capped at 2000, and a value that is no integer answers 422.                          |

## Measurements, Events, Alarms, Operations

| Id                             | The Docs Say                                                                                                        | The Platform Does                                                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `date-parameters-lenient`      | `dateFrom` and the other date parameters are `date-time` strings.                                                   | Fields may have one digit (`2026-1-3T1:0:0Z`), a bare date (`2026-01-01`) is accepted, a time without seconds (`2026-01-01T10:00Z`) or a word answers 422.              |
| `with-source-children`         | `withSourceDevices`, `withSourceAssets`, `withSourceAdditions`, and `withSourceChildren` include "related" sources. | They include the alarms or events of the source's children of that kind, recursively (`withSourceChildren`: every kind).                                                |
| `source-unknown`               | Nothing.                                                                                                            | `source=<unknown id>` is an empty page; with any `withSource*` parameter it is a 404.                                                                                   |
| `alarms-resolved-omitted`      | `resolved` defaults to `false`, which "will fetch all alarms with status ACTIVE or ACKNOWLEDGED".                   | Without the parameter, alarms of every status are returned. Only `resolved=false` filters.                                                                              |
| `alarm-deduplication`          | Alarms with the same source and type are deduplicated while active.                                                 | An `ACTIVE` or `ACKNOWLEDGED` alarm absorbs a new one of the same source and type: `count` and `time` change, `text` and `severity` stay, `firstOccurrenceTime` is set. |
| `alarm-unknown-source-404`     | An unknown source is a validation error (422).                                                                      | Alarms answer 404 for an unknown source; events, measurements, and operations answer 422.                                                                               |
| `time-unparsable-400`          | Invalid data answers 422.                                                                                           | A `time` that is no date answers 400 on measurement, event, and alarm creation.                                                                                         |
| `required-fields-422`          | Required fields are listed per body (`source`, `type`, `time`, …).                                                  | A missing required field answers 422 `undefined/validationError` "Following mandatory fields should be included: …", also for external ids.                             |
| `operations-status-filter-422` | `status` filters operations.                                                                                        | Operations accept one known status only: a list (`PENDING,FAILED`) or an unknown value answers 422.                                                                     |
| `measurements-newest-first`    | Range queries return the oldest measurements first.                                                                 | Measurements come newest first; `revert=false` together with a date range gives the oldest first.                                                                       |
| `measurement-by-id-405`        | `GET /measurement/measurements/{id}` answers 200 or 404.                                                            | With time series persistence (the default), reading a single measurement answers 405.                                                                                   |
| `series-validation-statuses`   | Series errors answer 400.                                                                                           | Missing `source`/`dateFrom`/`dateTo` and unknown aggregation values answer 400; an invalid interval or functions without an interval answer 422.                        |
| `series-missing-entries`       | Each value entry is a `{ min, max }` object.                                                                        | A series without a value at a time is `null`; with `aggregationFunction`, an empty bucket keeps only `sum` and `count` (as 0) and is `null` without them.               |

## Binaries, Notifications, Platform

| Id                             | The Docs Say                                                         | The Platform Does                                                                                                               |
| ------------------------------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `binaries-unknown-404`         | `GET`/`DELETE /inventory/binaries/{id}` answer 200/204, 401, or 403. | An unknown id answers 404.                                                                                                      |
| `binary-replace-empty-body`    | `PUT /inventory/binaries/{id}` answers 201 with the managed object.  | It answers 201 with an empty body.                                                                                              |
| `binary-fragment-empty-string` | `c8y_IsBinary` is an object.                                         | Uploaded binaries carry `c8y_IsBinary: ""`.                                                                                     |
| `unsubscribe-statuses`         | `POST /notification2/unsubscribe` answers 200, 401, or 403.          | Without a token it answers 422; an unknown token, or one without a connected consumer, answers 500.                             |
| `current-application-user-403` | `/application/currentApplication` describes the calling application. | With a user's credentials it answers 403 `security/Forbidden`; only application credentials (bootstrap or a service user) work. |
| `unknown-endpoint-404`         | Nothing.                                                             | A path the API does not have (`/inventory/nope`) answers 404.                                                                   |
| `wrong-method-405`             | Nothing.                                                             | A known path with another method (`POST /tenant/currentTenant`) answers 405.                                                    |
